# The generated AGENTS.md sets operating rules but not model routing

Mirage writes an `AGENTS.md` with the read-first list, lanes, branch, commit and pull request conventions, verification commands and evidence rules. It does not choose models or reasoning effort for agents, because those depend on each team's accounts and change faster than project docs.
