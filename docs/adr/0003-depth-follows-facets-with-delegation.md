# Documentation depth follows the project's facets, and any answer can be delegated

Mirage does not ship fixed profiles. The interview first settles the project's facets, then asks every question the documents for those facets need, so a corporate website gets full coverage of pages, content, SEO and hosting, and a mobile app with a backend gets full coverage of both. Every question carries the agent's recommendation. A busy owner can accept recommendations for one question, a round, a document or everything left, and each accepted recommendation is recorded as a delegated answer.

Decided by the owner on 2026-09-26.

## Considered options

- Fixed lite, standard and full profiles. Rejected because a profile either under-asks a small project with one deep area or over-asks a large one.

## Consequences

- A delegated answer unblocks work at once. The generated index lists every delegated answer so the owner can confirm them in one pass. A project that wants confirmation first sets `require_confirmed_delegation` in `.mirage/project.json`.
